# Run Full Access directly on the host for trusted local Projects initially

For the first personal/local Workbench slices, an explicitly trusted Project may run an Agent Session's Full Access Mode directly on the host, with the effective Access Mode always visible and independent from model or Work Intensity. An optional local isolation profile is deferred because it would add a second execution boundary before the official-runtime Adapter and durable coordination contracts are complete; this decision does not weaken runtime-owned authentication or authorize Full Access for an untrusted Project.
