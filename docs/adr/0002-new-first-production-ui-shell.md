# Build the first production UI as a new Electron, SolidJS, and Vite shell

The first production Workbench UI will be implemented directly over the runtime-neutral ProjectChannel rather than by copying OpenCode's application state or UI code. The owner approved A's three-pane desktop hierarchy with B's narrow-screen context strip; a small new Electron + SolidJS + Vite shell keeps that information architecture aligned with the proven coordinator contract, while OpenCode reuse and C's Project overview remain later decisions.
